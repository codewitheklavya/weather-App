# Weather App

A responsive weather application that allows users to search for any city and view real-time weather updates. The app fetches live data using the **OpenWeatherMap API** and presents it with a clean, minimal, and user-friendly interface.

## 🚀 Features
- 🌍 Search weather by city name  
- 🌡 Displays temperature, weather condition, and more  
- ⚡ Real-time data using OpenWeatherMap API  
- 🎨 Clean and responsive UI with **Tailwind CSS**  

## 🛠️ Tech Stack
- **HTML**
- **Tailwind CSS**
- **JavaScript**
- **OpenWeatherMap API**
